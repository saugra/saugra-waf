# Saugra Trademark Policy

This policy explains how the Saugra name, logo, and related branding may be
used. It is intended to protect users from confusion while still allowing fair
community discussion, packaging, and compatibility references.

This is not a software license. The Saugra source code is licensed separately
under AGPL-3.0-only.

## Protected Marks

The protected marks include:

- `Saugra`
- `Saugra WAF`
- The Saugra logo
- Saugra domain names, release names, badges, and visual branding

Permission to use the software does not grant permission to use these marks in a
way that suggests official origin, endorsement, sponsorship, or control.

## Allowed Uses

You may use the Saugra marks to:

- Refer truthfully to the Saugra project.
- Link to the official Saugra repository or documentation.
- Describe compatibility with Saugra.
- Package unmodified Saugra releases when the package clearly identifies the
  upstream project and does not misrepresent who built or maintains the package.
- Discuss Saugra in articles, tutorials, reviews, talks, and security research.

Examples:

```txt
Works with Saugra WAF
Unofficial package for Saugra
Forked from Saugra
```

## Uses That Require Permission

Ask for written permission before using the Saugra marks to:

- Name a company, product, hosted service, or commercial offer.
- Register a domain name, social account, app store entry, package namespace, or
  repository that could look official.
- Use the Saugra logo in marketing or paid services.
- Claim certification, partnership, official support, or endorsement.
- Sell services under a name that could confuse users about who provides them.

## Forks And Modified Versions

You may fork, modify, and redistribute the Saugra software under AGPL-3.0-only,
but modified versions must not imply they are official Saugra releases.

Modified versions should use a clearly different name or add a clear qualifier,
such as:

```txt
ExampleCorp WAF, based on Saugra
Unofficial Saugra fork by ExampleCorp
```

Do not call a modified product simply `Saugra`, `Saugra Pro`, `Saugra Cloud`,
or another name that makes it look like an official release.

## Packages And Distributions

Linux distributions and package maintainers may identify the software as Saugra
when packaging unmodified upstream releases or reasonable downstream patches.

Packages should preserve the license, copyright notices, and upstream project
metadata. If a package includes substantial downstream changes, its description
should make that clear.

## No Endorsement

Use of the Saugra marks must not suggest that the Saugra maintainers approve,
certify, sponsor, or provide support for a third-party product or service unless
there is a written agreement saying so.

## Reporting Misuse

Please report confusing or misleading use of Saugra marks through the maintainer
contact channel listed in the repository profile.
