# Saugra WAF Documentation

The repository [README](https://github.com/saugra/saugra-waf#readme) is the
primary entry point for installation, quick start, features, and common
commands.

Use the canonical guides for deeper material:

- [Administration](ADMIN_GUIDE.md): configuration, deployment, AI, operations,
  tuning, and troubleshooting.
- [Architecture](ARCHITECTURE.md): request processing, security model, rules,
  storage, and developer design.
- [Release process](RELEASE_PROCESS.md): packaging, APT signing, and publishing.
- [Roadmap](https://github.com/saugra/saugra-waf/blob/main/ROADMAP.md): current
  implementation status and planned work.

Saugra is an additional defense layer. It does not replace secure application
development, authorization, dependency management, or host hardening.
